# Purpose Haxe 4 port

## Summary

This version was ported using ChatGPT to Haxe 4 (as 2026-10-04).

## Why using AI for this port?

I loved this little game and it had some special meaning to me but couldn't find the time to make it playable on modern browsers as it used Flash technologies. A friend recommended to me to try making the port work using AI, which I did.

It wasn't an easy way, but this tool allowed me to convert the game and make it playable in single night of work.
